Live · Real Users · Real Payments

Tenant & Rent Management Platform

A live property-management platform handling real tenants and real money — billing, e-wallet reconciliation, contract tracking, and an audit trail built to survive scrutiny.

Caught before it shipped
  • A step-up verification gate for a sensitive account action fell back to "allow" instead of "block" when unconfigured — hard-blocked instead.
  • A "placeholder" payment image was actually a real, live payment destination reused from an old demo — traced and fixed everywhere it was referenced.
  • Five API routes were missing an explicit ownership check — caught in a pre-launch audit, not the initial build.

Client Engagement · Staged, Invoiced Delivery

Gift-Scheduling SaaS Platform

Built and maintained for a paying client — scheduled gift orders, client management, Stripe billing — delivered in staged, invoiced phases. The client liked the process enough to pay for a dedicated security audit as the next one.

Caught before it shipped
  • Raw database error messages were leaking to API clients across multiple routes — fixed everywhere after grepping the full codebase, not just the reported route.
  • An unauthenticated account-overwrite bug in the signup flow — closed.
  • Known dependency vulnerabilities — patched.

Client-Commissioned Build

Fraud-Resistant Inventory Management System

A multi-branch inventory system built for one client's real business — receiving, damage & disposal, low-stock alerts, exception reporting. Before writing a line of implementation code, I tried to defraud my own design.

The audit, before the build
  • 35 findings — 14 critical, 12 high, 7 medium, 2 low — each with a real attack scenario.
  • Every finding paired with a system-enforced control, not a policy note nobody follows.
